# News on Weather | OpenAPI Project

Esta API realiza a coleta e o armazenamento de dados climáticos realizando o armazenamento em um banco de dados relacional (PostgreSQL) a partir da [análise de modelagem do domínio do sistema](https://budkee.notion.site/Open-Weather-Map-3b2e4e5a58ec4898ad31f94c178ca2db?pvs=4). 

### Sobre o sistema

O sistema fornece uma arquitetura baseada em microsserviços utilizando o [modelo hexagonal de portas e adaptadores](https://dev.to/wsantosdev/design-ports-and-adapters-48mi).
